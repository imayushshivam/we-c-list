# We-C-List: Wishlist App for Shopify

We-C-List is a simple, lightweight wishlist app that allows customers to save products they're interested in for later.

## Features

- Easy-to-use wishlist button for product pages
- GDPR compliant data handling
- Dashboard for store owners to view wishlist data
- Customizable wishlist button appearance

## Installation

1. Search for "we-c-list" in the Shopify App Store
2. Click on "Install" to add the app to your store
3. Open the customization settings of your store
4. Navigate to the product page and add the "Wishlist Icon" block to your template

## Customization

The wishlist icon can be customized:
- Change the text displayed next to the icon
- Modify the color of the heart icon when a product is added to the wishlist

## GDPR Compliance

This app complies with GDPR requirements:
- Customer data can be exported upon request
- Customer data can be deleted upon request
- All shop data is removed when the app is uninstalled
